# Aster 使用指南

Aster 是一个本地优先的科研辅助工具。它把文献、原文 PDF、译文 PDF、标签、Markdown 笔记、PDF 标注和 AI 对话都绑定到同一个文献 ID 上。你在不同场景里看到的是同一份资料的不同工作视图。

## 1. 从 PDF 导入文献

在文献库点击“从 PDF 导入”，选择本地 PDF。Aster 会把文件复制到应用数据目录，并根据 PDF 内容和文件名生成元数据草稿。标题、作者、年份、来源、DOI 和标签都可以在确认前修改。

如果自动提取不准确，可以直接手动改。第一版优先保证导入闭环稳定，在线补全可在设置中启用或关闭。

## 2. 管理文献库

文献库使用紧凑表格展示标题、作者、年份、来源和标签。你可以搜索标题、作者、标签或笔记内容，也可以点击右侧标签墙过滤文献。

标签输入采用 chip 方式：输入标签后按回车即可创建。输入时会检索已有标签并给出建议。如果没有填写标签，系统会自动使用“未分类”作为兜底。

选中文献后可以编辑元数据、编辑标签、导入译文 PDF、打开文件位置、外部打开 PDF、删除文献或批量整理。当前筛选结果还可以复制为 Markdown 清单或 CSV 清单，方便贴到笔记、表格或汇报材料中。单篇文献和批量选中文献都可以复制 BibTeX，方便写论文时粘贴到参考文献管理流程里。

## 3. 阅读 PDF 和 Markdown

双击文献或点击“阅读”进入阅读场景。阅读器支持连续多页 PDF、原文/译文切换、缩放、页码跳转、鼠标浏览和平移。

阅读场景也支持 Markdown 模式，用来查看和编辑当前文献绑定的阅读笔记。笔记底层保存为 Markdown，并始终绑定到当前文献。

## 4. 标注与批注

阅读器提供鼠标、高亮、批注、下划线和区域框选工具。鼠标工具用于浏览；高亮、下划线和区域框选通过拖拽创建；批注通过点击页面位置创建。

右侧工作面板可以查看标注列表。标注支持删除和短时间撤销，批注内容也会保存到本地资料库。

## 5. AI 对话

AI 对话场景会围绕当前文献、标签、笔记和标注组织上下文，并把对话记录保存到本地 SQLite。当前版本先提供本地上下文对话底座，后续可以通过 AI Provider 接入 Codex CLI、Claude Code CLI、本地模型或其他服务。

## 6. 设置与资料库

设置页可以调整界面密度、默认阅读布局、元数据源优先级和在线补全开关。你也可以查看资料库路径、打开文件库、创建备份、复制诊断信息。

不要手动移动资料库里的 PDF。需要迁移或排查问题时，优先使用设置页中的资料库路径和备份功能。

Aster 会记住最近场景、选中文献、搜索和标签筛选、阅读模式、PDF 缩放以及右侧工作面板状态。下次打开应用时，可以尽量回到上次的工作位置。

## 7. 快捷键

- Ctrl+O：从 PDF 导入
- Ctrl+F：搜索文献库
- Ctrl+Enter：打开当前选中文献进入阅读
- Ctrl+1 / Ctrl+2 / Ctrl+3：切换文献库、阅读、AI 对话

## 8. 当前边界

当前版本已经具备本地文献管理和阅读闭环。后续重点会继续增强：更准确的在线元数据补全、文字级高亮识别、更多 PDF 标注细节、翻译 API、真实 AI Provider 和插件加载流程。
