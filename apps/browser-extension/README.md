# A4 Note 保存论文 · 插件 0.6.5

识别论文 → 点击文件夹 → 下载并导入。使用桌面软件图标；主界面保留桌面连接/重连与状态、论文标题/作者/标识、可展开的论文信息与摘要、原文/PDF链接及其状态、文件夹、下载和进度条。齿轮面板仅放帮助说明、详细错误和设置。

## 文件夹树与记忆

- “保存到”直接展示桌面真实文件夹树，点击整行选择目标，点击左侧箭头展开/收起；支持全部展开/收起。
- 沿用桌面文献库的30px行高、20px层级缩进和六色引导线；悬停/选中时强调祖先路径。
- 在本浏览器配置中记住上次选择和各目录展开状态。只使用 `chrome.storage.local` 保存文件夹ID、展开ID和格式版本，不保存目录名称、磁盘路径或论文内容，不云同步。
- 每次重新读取授权桌面的目录后才恢复有效ID。记住的目录被删除或层级异常时清除选择，不自动退回根目录；导入前后仍由桌面校验分类。
- 收起目录不会取消已选位置；下方完整路径提示和“定位”可重新展开选中项的祖先。
- “清除记忆”取消上次选择，并恢复根目录展开。卸载插件或清除扩展数据会移除记忆；普通重新加载/覆盖原目录升级通常保留。
- 方向键移动/展开/收起，Home/End移动到首尾，Enter/空格选择。移动键盘焦点不自动更改导入目标。
- 首次使用无预选；之后恢复上次选择。**仍须点击“下载并导入”，不会自动提交。** 请求被接收后锁定目标，避免重复提交或改错任务。

## 与已安装桌面配合

**本版需要配套桌面0.1.6及native-host 0.6.1；旧版0.1.5不支持新增能力。请先安装本轮完整安装器，再重新加载插件。** 插件双端检查分类和重试能力，并检查桌面逐文件进度、补充材料及正文入库门槛能力；不兼容时禁用提交，避免旧版静默保存缺PDF条目。本地安装包不等于已经发布到在线更新通道。

若仍在旧桌面，使用[官方发布页](https://github.com/AustinSuun/A4Note/releases/latest)中的完整安装器升级；只替换EXE不会更新注册组件。不要误用旧的 `artifacts/windows/latest` 本地产物，先核对同目录 `build-info.json`。

首次需要点击“连接桌面”并在桌面允许。授权有效时自动恢复连接，不重复弹窗。版本不兼容、授权撤销和断连会禁止导入；请更新完整安装器或重新连接，不关闭安全校验。

## 安装 / 更新插件

1. 等待采集或浏览器辅助传输完成。
2. 解压 `A4-Note-Capture-0.6.5.zip`，将 `A4-Note-Capture` 内文件覆盖到原来加载的插件目录。
3. Chrome/Edge扩展管理页点击“重新加载”，核对版本0.6.5。首次则使用开发者模式“加载已解压的扩展程序”，选择含 `manifest.json` 的目录。
4. 保持manifest公钥不变，沿用同一插件身份与授权。不要卸载重装来更新，以免丢失记忆。

右上角帮助面板内“插件设置与更新”可在用户点击后请求固定GitHub API源的访问权限，检查正式发布中的配套ZIP。解压加载的插件不能自行替换文件，只检查并下载，之后需人工重新加载。当前本地交付的版本可能比公开更新通道更新；不会降级。

## 信息与文件

正文PDF和结构化元数据分别保存：标题、作者、机构/ORCID（有则保存）、摘要、关键词、DOI/arXiv/PMID/PMCID、出版物、日期、原始元标签、来源证据与文件候选。缺失字段不编造，PDF链接不等于已下载或验证；正文未成功时不新增文献条目；既有文献不自动删除。独立失败任务暂保留，用于显式重试。桌面“论文信息与附件”可查看这些记录。

自动下载失败可进入帮助面板的“下载遇到问题？”使用浏览器辅助。辅助需要明确授权具体站点，并保持弹窗打开；不会绕过付费、验证码或DRM。只保存文件到下载目录不等于入库。

## 权限与边界

常驻权限：activeTab、scripting、downloads、nativeMessaging、storage（仅本地文件夹选择记忆）。没有cookies/debugger权限，不在网页暴露原生连接，不后台扫描页面。网页采集仅在用户打开插件时读取当前详情页；普通网页或浏览器系统页可能无法识别。

分类上限2000个，超过64层、循环/孤立节点不允许作为导入目标。论文已有分类时由桌面保留原分类。真实站点登录态、下载限制和用户资料副本验收不由静态构建替代。

## 进度与补充材料

- 总体条表示文件校验完成数；逐文件条表示收到的字节数/已知总量。未知总量用不确定进度条；全部文件已校验仍需完成入库，成功图标只在完成入库后显示。
- 连接、读取、校验与入库阶段由真实任务返回；当前任务轮询1秒，15分钟后暂停自动刷新，可手动继续。不把窗口关闭当成取消桌面任务。
- 总体重试沿用同一captureId；失败文件可按index单独重试。已校验的缓存重新核验后复用，不重新联网下载。保持冻结的分类和原任务内容。
- 支持明确提供的补充PDF、CSV/TSV/TXT/JSON/XML、XLS/XLSX、DOC/DOCX、PPT/PPTX、ZIP/GZ/TGZ/TAR、常见图像/音视频及H5/HDF5/NC数据文件。每文件50MiB、采集缓存1GiB上限仍保留。
- 格式优先由正文角色、响应文件名、URL或已知Content-Type确定；无法确定格式、登录HTML或明显可执行内容会拒绝。非PDF采用大小/部分格式头/哈希检查，不代表完成恶意软件扫描或数据语义验证。
- 非PDF只保存原始字节，不执行、解压或直接调用默认应用；在文献附件中点击后打开所在文件夹。网页快照及普通链接不下载入库。

## 网站覆盖边界

通用规则读取citation/DC/DCTERMS/PRISM/eprints等元数据及ScholarlyArticle JSON-LD；新增明确PDF按钮、唯一PDF下载链接及补充材料区域线索。已有arXiv/PMC专门规则。页面有DOI不等于正文可访问；链接有多个且无法唯一确定时不猜测。

这些通用规则可适用于采用相应标记的不同学科网站，**不等于已逐站完成Elsevier、Wiley、Springer Nature、IEEE、ACM、ACS、APS等平台适配或实测**。动态按钮、付费/机构权限、验证码、跨域跳转与补充材料二级目录仍可能失败；不绕过权限、不自动使用浏览器辅助。没有新增编号输入查询，也没有ISBN/ADS专门适配。

## 界面与进度定位（0.6.5）

桌面确认接收下载或重试后，立即显示已知文件的等待读取状态区域并滚动到这里；不是提前宣称已开始下载。帮助面板中重试会返回主界面的进度区域。每个明确动作仅定位一次，轮询和完成通知不重复拉动页面；刷新保留同一任务附件列表内部的滚动位置。重新识别会撤销尚未执行的定位。尊重减少动画设置，不主动移动主界面的键盘焦点。

统一400px宽度、间距、卡片和按钮，固定顶部工具栏/底部下载按钮；保留完整论文标题、作者、标识符、链接状态和论文详情。移除重复信息徽章，下载区域增加短标题，蓝色表示处理中、绿色表示已入库、暖色表示失败。桌面版本仍为0.1.6，无需重新安装。
