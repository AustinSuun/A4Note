# 插件 0.6.1 · 更新功能

弹窗底部 **插件设置与更新 → 检查插件更新**：只在点击时请求 api.github.com 的访问权限，查询固定官方仓库的稳定 Release，不上传论文或资料库内容。发现更新后，可显式下载配套 ZIP。版本按数字比较，不降级；拒绝非官方资产地址和不完整发布。

解压加载版受浏览器限制，**不能自动替换自身文件**。请先等待采集/辅助传输结束，下载并解压覆盖原插件目录，再在 Chrome/Edge 扩展管理页点击重新加载，核对版本。下载受理不代表安装完成；插件不会主动重启、安装或加载远程代码。插件身份 key 保持不变。

桌面 0.1.5 在 **设置 → 软件更新** 提供签名检查、下载与明确确认后安装；关于页保留快捷入口。原生通信组件沿用兼容的0.6.0，旧组件仍需完整桌面安装器更新。

# A4 Note 保存论文 0.6.0

识别论文 → 选择文件夹 → 下载并导入。采用与桌面相同的图标，主界面只保留论文摘要卡、文件夹选择和主操作；论文信息、下载补救与进度按需展开。

**本版必须搭配桌面0.1.4及其安装器内的通信组件。** 单独更新插件或替换桌面EXE不足以更新原生主机。首次需要明确授权，之后不会自动弹授权窗口或自动提交论文。

## 安装与首次连接（Windows Chrome / Edge）

1. 先备份资料，退出旧版桌面软件。使用配套的 `artifacts/windows/latest/A4 Note_x64-setup.exe`，安装器会为当前Windows用户注册Chrome和Edge通信组件。核对同目录 `build-info.json` 的 `captureTransport` 为 `native_messaging`、`captureExtensionVersion` 为 `0.6.0`；不满足时需先重新打包，不能用旧包搭配本扩展。
2. 解压 `A4-Note-Capture-0.6.0.zip`。在Chrome或Edge扩展管理页开启开发者模式，加载**含 manifest.json 的 A4-Note-Capture 文件夹**。若曾加载旧版，请移除旧扩展或重新加载这个新文件夹，避免工具栏同时保留两版。保留 manifest 中的固定公钥，不需要查看/填写扩展ID。
3. 启动**已安装的新版** A4 Note，固定扩展到工具栏并打开它。扩展自动查找通信组件；首次点击“连接并在桌面授权”，在桌面弹窗选择“允许并记住”。不需要链接、端口或配对码。
4. 以后打开扩展会自动恢复授权连接。撤销入口是桌面「设置 → 资料库 → 浏览器论文采集 → 撤销浏览器授权」；重新授权须再次主动确认。Crossref / Europe PMC 补全开关也在此处。
5. 在论文**详情网页**点击工具栏扩展，弹窗自动识别当前页；仅有普通网页标题或没有可信论文标题时不显示导入入口。识别不自动提交、下载或申请桌面授权。
6. 识别成功后直接展示桌面真实文件夹列表（含父子完整名称）。请选择分类，再点击 **下载并导入文献库**。不预选或静默回退分类；桌面新建分类后可刷新列表。
7. 提交后在弹窗展开下载与入库进度，保持弹窗打开时自动刷新最多2分钟，之后可手动刷新。关闭弹窗不停止已经接收的桌面队列任务。不要在扩展管理页或浏览器内部PDF查看器上识别。

**连接排错**：提示未安装组件时，重装本版安装器；单独复制/运行裸EXE不会注册或带齐通信组件。提示未运行时启动已安装新版，再点“重试连接”；提示版本不匹配时退出旧路径的软件。企业策略禁止Native Messaging时需管理员允许，本扩展不会绕过策略。桌面未运行时不会静默启动应用。

## 下载失败时：两种补救

### 浏览器辅助入库

适用于原生直连失败、浏览器有代理或已有登录/机构访问权限的情况：

1. 先选择分类并点击“下载并导入文献库”，等待桌面自动下载结束并显示“需要处理”。
2. 在同一次识别的 PDF 候选下点击“自动下载失败？浏览器辅助入库”。
3. 浏览器会请求访问**这个论文站点**的权限；按需允许。建议先在普通标签页完成合法登录。
4. **保持扩展弹窗打开**。扩展使用浏览器网络及可用的站点登录态获取 PDF，再通过已授权的原生通道分块发送给本机；不读取 Cookie 内容，也不把 Cookie 上传到桌面。
5. 桌面重新检查 PDF 结构、页数和 SHA256 后排队，补入同一篇文献。刷新确认“已入文献库”。

辅助下载不会绕过付费墙、验证码或站点限制；拒绝自动跨站重定向。某些 SameSite Cookie、签名链接、跨域 CDN 和 DRM 场景仍须手动处理。关闭弹窗可能中断传输，失败可重试；若状态卡住，桌面取消后重试，或重启软件后重试。

### 浏览器下载后，手动补充本地 PDF

点击“仅保存到下载目录（不入库）”，确认实际保存的是 PDF。然后在 A4 Note 文献表选中对应论文，在详情的“采集来源与附件”中选择补充本地 PDF。

该操作关联已有文献，不另建一篇、不覆盖主 PDF 或标注；已有正文时保留为另一版本。没有正文的记录补上首个主 PDF。非 PDF 的代码、数据集、ZIP 等保留来源链接，不自动登记为 PDF。

## 分类与失败保护

- 浏览器读取分类需要已授权的 Native Messaging 连接；旧组件可能支持hello却不支持list_folders；本版同时校验桌面和通信主机的独立能力，新主机对未知操作会返回明确错误而非直接退出。旧0.4.0组件没有分类能力，新扩展会要求升级配套桌面安装器，不会在旧版中静默导入根目录。
- `targetFolderId` 随任务持久保存。提交时校验分类，真正创建论文时在同一数据库事务内再校验；下载期间分类被删除会提示处理，不自动改存默认分类。
- 新论文进入所选分类；DOI/哈希/arXiv识别出已有论文时保留原分类与用户编辑，进度会显示实际分类。后续辅助PDF沿用原任务，不另选分类或重复建记录。
- 提交开始后锁定分类和任务快照。响应不确定时仅重试同一任务，避免同一弹窗中连点重复入队；明确的分类无效错误会重新开放选择。重新识别是一次新的采集。
- 没有正文候选或下载失败时可能仅保存论文信息，进度明确显示“正文PDF仍待补充”，不冒充PDF已成功导入。
- 分类列表上限2000项，过多时明确报错；父级缺失或循环的分类显示异常且不可选择。当前不支持在扩展中新建分类。

## 元数据与文件保存

- 支持 citation / DC 元标签、明确的摘要 DOM 和 ScholarlyArticle JSON-LD；保留原始数据与逐字段来源证据。多篇结构化对象无法确定时不猜选。
- DOI 精确匹配 Crossref，PMCID 精确匹配 Europe PMC；只填页面缺失字段，保存提供者原始响应。可在桌面设置关闭外部补全，避免把 DOI / PMCID 发给这两家服务。
- arXiv 提交与修订日期分开，不冒充期刊 online 日期。arXiv 版本链接保留在原始来源中，以基础 arXiv ID 关联版本。
- 文献表保留既有手动标题、作者、主 PDF、标注和笔记，不静默以新抓取结果覆盖它们。新采集记录及更完整信息可在来源详情查看；元数据冲突的自动解决 UI 尚未提供。
- 同一采集 ID 幂等；跨采集按 DOI、正文哈希或基础 arXiv ID 关联。冲突或多义匹配要求人工核对。缺少标识与 PDF 时，不凭标题强行合并。
- 正文/补充 PDF 保存在资料库的 `files/papers/.../captures/...`；完整元数据快照进入资料库 SQLite。它们随现有资料库备份一起保存。
- 下载队列及临时副本仍在应用数据目录的 `A4CaptureData`（与 `AsterData` 同级），**不在旧资料库备份范围内**。若需要连未完成任务一起保留，关闭软件后额外复制整个 `A4CaptureData`。
- 文献详情显示最近20份快照和已登记文件；更早快照仍在数据库中，不因界面限制删除。

## 通信、安全与限制

- 主操作同时保存正文PDF和结构化元数据：标题、作者、机构/ORCID（有则保存）、摘要、关键词、DOI/arXiv/PMID/PMCID、期刊/出版社/卷期页码、各类日期、原始元标签、逐字段来源及附件候选。网页缺什么就标记缺失，不从文件名猜造；仅有信息入库会明确提示PDF待补充。桌面“论文信息与附件”可直接阅读结构化信息，原始JSON在来源详情中折叠保留。

- 常驻权限：activeTab、scripting、downloads、nativeMessaging；没有cookies、debugger、storage或localhost权限。浏览器辅助下载仅按点击申请相应HTTPS站点权限，不预先授予全站访问。
- 浏览器通过stdio主机与桌面当前用户命名管道通信，不监听HTTP端口。固定扩展身份白名单、用户/SYSTEM管道ACL、禁止远程客户端、双方进程路径校验；授权持久保存且可撤销。公钥不是秘密，不能防止已控制本机同一用户账户的恶意程序。
- 安装器按用户注册Chrome/Edge主机；卸载仅删除仍指向本安装的注册项，不删除文献或覆盖其他安装的注册。当前未上架扩展商店；将来上架必须协调商店身份，不可随意换公钥。
- 原生下载只允许公开 HTTPS/443，检查每次重定向及 DNS 公网地址，并固定解析结果；不继承系统代理和浏览器登录态。需要浏览器网络时使用辅助入库。
- 单文件最多50MiB，采集目录下载检查约1GiB，最多1000任务；每个采集最多100候选、初始JSON请求1MiB。界面显示最近100任务，暂无清理/分页界面。
- 一次只接受一个浏览器 PDF 上传；每次上传最多180秒、每块192KiB，空闲连接90秒超时。内容校验在后台执行；结构检查不等于病毒扫描或正文与元数据语义匹配，PDF 解析器尚未进程隔离。
- 已落盘文件重验后复用，未完成文件重下；不是 HTTP Range 断点续传。崩溃可能留下暂存副本，暂未做自动清理。
- 目前为开发者模式加载的试用扩展，未上架 Chrome/Edge 商店。请优先使用资料副本试用。
