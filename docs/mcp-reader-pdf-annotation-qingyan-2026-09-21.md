# PDF 阅读标注修复（青砚，2026-09-21）

## 任务

- 项目任务：`b6c1a566-c96f-458a-9c68-64de6df53c77`
- 分支：`fix/pdf-annotation-qingyan`
- 范围：高亮/下划线几何、文本标注默认值与字号菜单、跨页橡皮擦除、工具栏色点和行内控件。

## 实现

- 高亮按选区字形框比例收窄并下移上沿；下划线按字高计算线宽、避开下降部并向上收紧，避免跨相邻行。
- 文本默认字号改为 24；字号完整覆盖 2–64、步进 2；初始宽度约 9em，默认单行框，换行后自动增高。
- 工具设置进入版本化本地持久化；历史默认值 13 迁移为 24，其他有效值保留，非法值规范到 2–64 偶数。
- 工具栏及行内字号选择器使用可滚动自定义菜单，支持点击、键盘和滚轮；Escape 只关闭菜单。
- 橡皮改为线段碰撞而非仅采样点；中段擦除生成空值分隔的独立笔迹段并重算边界，整笔命中仍可删除，保留撤销/重做语义。
- 擦除预览在文档内部页边和页间隙保持连续，只在文档外边界清除。
- 工具栏色点为 9px 且有 1.5px 边框；行内操作按钮和图标扩大。
