# 阅读器侧边栏笔记 Markdown 功能集成任务发布报告 (2026-09-23)

## 1. 发布概况
- **Task ID**: `cccd824e-a798-4922-8db5-8e14b6d7b83b`
- **任务标题**: 阅读器侧边栏笔记功能增强：全量集成 Markdown (MD) 编辑与渲染能力，复用主笔记模块功能
- **发布角色**: Dispatcher Agent (`ArenaDispatcher`)
- **任务状态**: `queued` (已进入队列，等待执行 Agent 授权领取)
- **优先级**: `high`
- **Revision**: 1

## 2. 核心需求要点
1. **侧边栏/浮动阅读笔记全量集成 Markdown (MD) 编辑器与渲染引擎**:
   - 将主笔记模块中的全套 Markdown (MD) 编辑与渲染能力复用并迁移至阅读器右侧“阅读笔记”侧边栏面板中。
   - 完整支持各种 Markdown 语法（标题 H1-H6、加粗/倾斜、有序/无序列表、代码块/语法高亮、引用块、表格、数学公式 LaTeX、超链接与图片嵌入等）。
2. **快捷工具栏与模式切换**:
   - 在侧边栏笔记顶部/浮动条中提供 Markdown 常用格式快捷工具栏，支持编辑模式与实时渲染模式（或所见即所得编辑器形态）。
   - 保留与阅读器上下文（如文档名称、页码/锚点标签 `文本框 · 第 X 页`）的自动绑定与快捷引用机制。
3. **数据同步与持久化**:
   - 确保侧边栏 Markdown 笔记内容变动时实时自动保存（`已保存` 状态），并与主笔记库实现无缝双向协同。
