# A4 Note 0.1.9

## Markdown 与笔记

- 正文默认16px、舒适行高1.65，调整标题层级与段落空行显示；不删除原文空行。
- 保持原有界面字号与比例，保留已保存的字号设置；旧正文20px可在设置中自行调为16px。
- 引用和代码中的中文跟随正文字体，代码英文数字优先等宽。
- 修复脚注上标过小、返回正文定位与悬浮预览背景透明。
- 改进表格边缘控制、选区背景、单光标编辑及阅读/编辑文末留白。
- 图片工具支持铺满正文、宽度与对齐操作；不改变原图内容。
- 文件树隐藏Markdown扩展名，为其他文件显示彩色类型标签，不重命名文件。
- 笔记悬浮栏使用更紧凑的双排布局，阅读与笔记浮栏统一较轻的磨砂样式。

## 阅读与更新

- 统一编辑/阅读、列表/总览与原文/译文/对照切换外观。
- 阅读标题栏按实际可用宽度切换紧凑入口，保留缩放、译文及对照同步操作。
- 改进PDF视口中心缩放、拖拽与标注历史/保存队列的一致性。标注历史是当前会话内状态，不是跨重启历史。
- 更新说明逐项显示，下载进度与备份确认更紧凑。更新前备份仅覆盖资料库，不含外部Markdown文件。
- 配套浏览器插件仍为0.6.5。
