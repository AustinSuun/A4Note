## 实现

1. **记住最近的开放模式**：新增 `lastOpenMode`，覆盖 split / floating / writing。关闭只改变可见性；入口、快捷键、新建笔记及面板页签的重开路径统一读取该字段。旧数据依次从开放的 mode、有效 lastOpenMode、previousMode、旧 wideMode 迁移，损坏字段安全回退。窄窗的临时 floating 不覆写用户选择。写作态“返回论文”仍保留原先回到上一布局的语义，不冒充真正收起。
2. **按论文隔离**：保存 effect 只向当前状态所属论文写入，并先于换论文加载；避免短暂将 A 的偏好写入 B。浏览器回归实际截获 storage 写入序列验证。
3. **滚动壳与正文分离**：编辑器/只读预览的滚动层全宽，720px 限制只作用于正文；预览用内部 padding 居中。笔记专属 `workspace-panel-content` 的 padding 归零、主体高度占满，其他面板默认间距不变。浮动 dock 边距缩至 4px。
4. **四角与入口**：四角仍是 26px 命中区，弧线 4px、外移 4px、半径 14px，与 10px 卡片圆角共圆心贴合；原鼠标/方向键算法不变。悬浮右缘入口 24×72px，主题化底色/边框，鼠标及键盘焦点显示“短按收起 · 长按切换模式”。菜单展开时隐藏引导，保留短按、长按、右键、方向键与 Shift+F10。
5. **主题与边界**：笔记主体和 dock 改用主题 surface，修复深色主题下旧白底低对比。右侧预留区 32px，使入口与角柄不被卡片覆盖；不改 FLIP 产品逻辑。
