## 2. 修正后的核心需求要点
1. **原文 / 译文 / 对照 视图切换快捷键**:
   - 在阅读界面顶部分段模式（原文、译文、对照）新增快捷键循环/直接切换视图形态，方便用户无缝快速切换视图形态。
2. **缩放快捷键更正为 Ctrl + 鼠标滚轮**:
   - 界面目前已支持 `Ctrl + 鼠标滚轮` 缩放，需将快捷键体系与提示浮层中展示的缩放快捷键**更正为 `Ctrl + 鼠标滚轮`（Wheel Up / Down）**，不再展示或使用原本旧的按键快捷键。
3. **快捷键提示浮层视觉防淹没优化 (Backdrop Blur & Contrast)**:
   - 优化按住 `Ctrl` 浮现的快捷键提示浮层（包含右侧侧边快捷键提示浮层），增加半透明防护背板与毛玻璃模糊（如 `backdrop-filter: blur()`，高对比度容器背景），防止提示文本与底图/PDF文档文本重叠交错导致“被背景文字淹没、看不清”的体验问题。
