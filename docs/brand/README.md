# A4Note Logo Assets

这是一套 A4Note 矢量 Logo 资产，围绕产品特性设计：

- A4 页面：笔记、PDF、资料页、手稿。
- 折角：文档和页面识别。
- 高亮线：PDF 标注、摘录、Markdown 标记。
- 节点连接：双链、知识图谱、关系操作。

## 文件

### 当前推荐版本：V3c

- `a4note-logo-v3c.svg`：当前推荐主 Logo。
- `a4note-app-icon-v3c.svg`：当前推荐软件图标。

- `a4note-wordmark-v3c.svg`：当前推荐字标组合。
- `a4note-logo-board-v3c.svg`：当前推荐展示板。
- `a4note-logo-v3c-notes.md`：V3c 优化说明。

## 设计标准

- 小尺寸优先：图标不依赖小字，32px 下仍能识别页面和连接节点。
- 核心隐喻控制在两个以内：页面 + 标注/连接。
- 主图标颜色控制在 2-3 个主色：墨蓝、青绿、纸白/浅灰。
- 不走书法、羽毛笔、学术徽章风格，保持现代知识工具感。
